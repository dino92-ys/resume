## 2. 연습 진행 방법

1. 면접관 역할은 한 번에 질문 하나만 제시합니다.
2. 첫 답변은 60~90초 안에 마칩니다. 요청받은 프로젝트 개요만 2분까지 사용합니다.
3. 답변에서 모호한 기술 선택이나 수치를 골라 후속 질문을 1~2개 합니다.
4. 답변 중에는 메모를 보지 않고, 종료 후 부족한 사실을 확인합니다.
5. 회차가 끝나면 개선할 항목을 세 가지 이내로 정합니다.

## 5. 회사에 할 역질문 후보

실제 면접에서는 남은 시간에 맞춰 1~2개를 선택합니다.

- 이 직무에서 입사 후 가장 먼저 해결할 과제와 기대 결과는 무엇인가요?
- 현재 RAG의 검색 품질과 응답 품질을 어떤 데이터와 기준으로 평가하고 있나요?
- 에이전트가 담당하는 업무와 사람이 검토하는 경계는 어떻게 구성되어 있나요?
- 데이터 파이프라인 개발과 모델·서비스 개발의 역할은 어떻게 나뉘나요?
- 공고에 언급된 폐쇄망·온프레미스 환경에서 모델 배포와 갱신은 어떻게 운영하나요?

채용 조건 별도 확인: 전체 경력과 해당 직무 관련 경력을 어떻게 산정하는지, 공고의 경력 5년 이하 조건이 어떻게 적용되는지 채용 담당자에게 확인할 수 있습니다.
