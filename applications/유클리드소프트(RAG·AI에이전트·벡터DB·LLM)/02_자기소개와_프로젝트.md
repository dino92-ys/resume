## 4. HK이노엔 — 2분 이내 설명

### 답변 초안

> HK이노엔 AI 챗봇에 공급할 데이터의 수집·적재를 단독으로 담당했습니다. 외부 규제 정보를 수집하는 파이프라인과, 사내 6개 기간계 시스템의 데이터를 옮기는 내부 ETL로 나뉩니다.
>
> 외부 수집에서는 5개 도메인 25개 게시판을 처리하고, PDF·HWP·HWPX·DOCX·XLSX·ZIP 6종 첨부에서 본문을 추출했습니다. 특히 LLM 요약 단계의 타임아웃을 해결하는 과정이 중요했습니다. 실제 입력을 측정해 보니 자재명 부분 문자열 매칭으로 대형 표 전체가 입력되고 있었습니다. 첨부에 자사 상호가 있는 경우 회사명으로 관련 내용을 선별하도록 바꿨습니다. 그 결과 HWPX 사례에서는 79,692자에서 514자로, PDF 사례에서는 64,026자에서 223자로 입력을 줄였습니다.
>
> 적재는 preview·rollback·commit 모드로 나누고 행 단위 트랜잭션과 단위 테스트 71개로 검증 체계를 구성했습니다. 내부 수집에서는 메타데이터로 2,000개 이상의 Hive External Table DDL을 자동 생성했습니다. 제 핵심 기여는 데이터가 AI에 전달되기 전의 수집·정제·적재 과정을 구현하고, 장애 원인을 실제 입력과 실행 결과로 확인해 해결한 점입니다.

## 5. 위니쿠키 — 확인된 설명과 보충할 내용

### 확인된 범위의 답변 초안

> 위니쿠키는 실제 수제 쿠키 전문점의 메뉴·가격·영업시간 문의를 자동 응대하기 위한 로컬 AI 챗봇입니다. Bllossom-3B를 Apple Silicon 환경에서 MLX 기반 LoRA로 파인튜닝하고, 46개 사실 문서를 ChromaDB에 저장해 bge-m3로 검색하는 RAG 파이프라인을 FastAPI로 구성했습니다. 검색은 코사인 거리 기준 Top-3으로 수행하고 `distance ≤ 0.45` 결과만 프롬프트에 넣으며, 통과 문서가 없으면 LLM을 호출하지 않고 정보 없음 응답을 반환합니다. 이후 Discord 봇이 FastAPI를 호출하도록 연결했습니다. 파인튜닝은 말투와 도메인 응답 형식을 맞추는 데 사용하고, 최신 사실의 근거 제공과 환각 완화는 RAG가 담당하도록 역할을 분리했습니다.

근거: 개발자 프로필 대표 프로젝트 3, 이력서 AI/ML 프로젝트. 이 문단은 2분 설명의 시작 부분입니다. 아래 사실을 확인한 뒤 완성합니다.
