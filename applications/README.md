# applications — 회사별 지원 문서

회사별로 파생한 지원 문서를 보관합니다.
**루트의 기본 문서(md 4종)는 여기 작업 때문에 수정하지 않습니다.**

## 디렉토리 규칙

```
applications/YYYY-MM-회사명/
├─ JD.md            # 채용 공고 원문 (요약 없이 그대로)
├─ 이력서.md         # 기본 문서에서 파생, JD 키워드에 맞춰 조정
├─ 자기소개서.md      # 기본 문서에서 파생
├─ 01_포트폴리오_발표_대본.md       # 제출 화면 + 말할 내용
├─ 02_프로젝트별_기술해설과_예상질문.md # 코드 복습 + 기술 질의응답
└─ NOTES.md         # 지원일, 전형 단계, 결과, 회고 (선택)
```

예: `applications/2026-09-당근마켓/`

## 작업 순서

1. 디렉토리 생성 후 `JD.md`에 공고 원문 저장
2. JD에서 필수 요건 / 우대 요건 / 반복 키워드 추출
3. 기본 문서와 대조해 매칭·부족 항목 정리
4. 매칭 항목을 앞으로 끌어올린 파생본 작성

자세한 지침은 저장소 루트의 `AGENTS.md` 6장을 참고하십시오.

## 면접 준비 기본 방식

01을 보며 제출 포트폴리오 발표를 연습하고, 02에서 같은 프로젝트의 코드를 열어
동작·선택 이유·한계를 복습합니다. 발표 이후 기술 질문도 02로 준비합니다.
문서 작성 기준은 `AGENTS.md` 9장을 따릅니다.

공고 분석과 모의면접 기록은 보조 자료로 유지합니다. 기존 폴더 이름과 이전 준비 문서는
보존하며, 회사별 README에서 새 01·02와 과거 문서를 구분합니다.
